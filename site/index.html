工作流

截图只是开始。
接下来才是重点。

系统截图把图片放在桌面，SnapGlass 把它放进下一步：挂上架、识别、标注，或者直接拖进正在用的窗口。

1

截下来

区域、窗口、全屏、所有显示器或滚动长图。松开鼠标，动作栏就在选区旁边。

2

挂上架

最近几张截图按顺序挂在屏幕边缘。拖动排序，键盘选图，跨屏跟随，空闲时收成细把手。

3

拖出去

把卡片拖出架体，它就是一个真实文件。落进 Finder、浏览器上传区、微信、飞书或 Slack。

功能

该有的都有，
不该有的没有。

没有账号，没有云同步，没有订阅。每一个功能都围绕“截完这张图之后要做什么”设计。

截图与滚动截图

区域、自由圈选、窗口、全屏、所有显示器；滚动长图逐帧采集并拼接。基于 ScreenCaptureKit，支持混合缩放与 Retina 像素。

PNG / JPEG · 1x / 2x

截图架

最近截图挂在屏幕边缘，拖动排序，拖出即文件。支持键盘模式、跨屏跟随、卡片数量与透明度调整。

拖出即文件

OCR 与智能动作

Apple Vision 本地识别，超大图自动分块。识别到验证码、链接或邮箱时，直接给出复制、打开或发邮件。

完全离线

标注与分享外观

8 种标注工具，完整撤销重做。背景、留白、圆角、投影、描边在画布上实时预览，复制出去就能发。

v1.7 分享外观

条码与二维码

QR、Code128、EAN、PDF417、Aztec、DataMatrix。动作栏按 S 直接识别，R 重截动画码，结果一键复制或打开。

不进编辑器

置顶

⌘P 把选区钉在屏幕上。拖动、缩放、调透明度，右键复制图片或文字；置顶内容不会进入录屏或后续截图。

10%–800%

录屏与录音

显示器、窗口或区域；系统声音、麦克风或两者。原子发布、10 秒 checkpoint、59 分钟分段，界面卡死也会自动保存。

MP4 / M4A

常见问题

装之前，
你可能想知道。

首次打开提示「无法验证开发者」怎么办？

打开「系统设置 → 隐私与安全性」，在安全性区域点「仍要打开」，然后再次确认。SnapGlass 没有 Apple Developer ID，这是自签名应用的正常首次流程；固定证书让后续自动更新不再重复授权。

需要哪些系统权限？

「屏幕录制」用于截图、滚动截图、录屏与系统声音；「麦克风」仅在选择麦克风作为录音来源时需要。拒绝某一项只会禁用对应功能。

截图或文字会被上传吗？

不会。截图由 ScreenCaptureKit 在本机捕获，OCR 使用 Apple Vision 本地框架，条码使用本地 Vision barcode。没有遥测，没有后台上传。只有你主动检查更新、主动下载 Tesseract 语言包，或明确开启自动检查更新（每天最多一次）时才会联网。

支持 Intel Mac 和哪些语言？

Release 提供 Universal 二进制（arm64 + x86_64），最低 macOS 13.0。界面支持简体中文、English、日本語、한국어，并跟随系统语言。

历史记录和录屏文件存在哪里？

截图与 OCR 文本在 ~/Library/Application Support/SnapGlass/History/v2/，使用 AES-256-GCM 加密；缩略图未加密。录屏 / 录音成品在你选择的录制目录中，未加密。详见 隐私声明。

录屏没有声音？

先确认录制来源是显示器、窗口或区域，并开启了系统音频；系统音频需要「屏幕录制」权限。若系统音频启动失败，SnapGlass 会继续录视频，并在保存后提示「系统音频未能录制，视频已保存」，不会让整段录制作废。

和系统截图怎么选？

只需要「截完即复制」时，系统截图足够。需要截图架取用、滚动长图、识别后直接办事、分享外观或录屏录音时，用 SnapGlass。两者可以共存，快捷键不冲突。

如何彻底卸载？

退出 SnapGlass，把应用拖进废纸篓；如需删除本地数据，再删除 ~/Library/Application Support/SnapGlass/、~/Library/Preferences/com.snapglass.app.plist 与 ~/Library/Logs/SnapGlass/。录屏 / 录音成品在你选择的录制目录中，需要单独删除。
